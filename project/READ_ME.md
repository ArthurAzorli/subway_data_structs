O programa utiliza uma arquitetura em camadas, onde cada camada é responsável por uma parte específica do sistema. A camada de apresentação é responsável por interagir com o usuário, a camada de negócios é responsável por processar as regras de negócio e a camada de dados é responsável por armazenar e recuperar os dados do sistema.

### File Repository
Simplifica a abertura, leitura e escrita de arquivos.

### Subway Header Repository
Define a estrutura e é capaz de ler e escrever os dados do cabeçalho do metrô.

### Subway Record Repository
Define a estrutura e é capaz de ler e escrever os dados dos registros do metrô.
